# Aplicativo-de-Lista-de-Tarefas-
Desenvolvimento de um aplicativo mobile para gerenciamento de tarefas e usuários, com recursos voltados à organização e ao acompanhamento de atividades do dia a dia.

O aplicativo permite organizar tarefas de acordo com seus níveis de prioridade, facilitando a visualização e o gerenciamento das atividades. O projeto também contempla funcionalidades relacionadas ao gerenciamento de usuários e notificações, com integração ao Firebase para suporte aos recursos da aplicação.

Principais funcionalidades:

Gerenciamento de tarefas e usuários.

Organização de atividades por nível de prioridade.

Notificações relacionadas às tarefas.

Integração com Firebase.

Interface mobile desenvolvida com foco na organização e facilidade de uso.

Tecnologias utilizadas: React Native, JavaScript e Firebase.
